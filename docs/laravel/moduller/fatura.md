# Fatura Modülü

## Fiş Türleri
- Satış Faturası
- Alış Faturası
- Satış İade Faturası
- Alış İade Faturası
- Hizmet Satış Faturası
- Hizmet Alış Faturası

## Ödeme Tipleri
- Vadeli
- Nakit (Kasa)
- Banka
- POS

## Listeleme
- Filtreler: Cari, Tarih Aralığı, Fatura Türü, Arama

## Form Alanları
- Tarih, Fatura No, Açıklama, Cari
- Ödeme Tipi ve Ödeme Hesabı
- Stok/Hizmet satırları

## Import
- Fatura import şablonu `Fatura İşlemleri` sayfasını kullanır.
- Peşin ödeme fişleri otomatik oluşturulur.
