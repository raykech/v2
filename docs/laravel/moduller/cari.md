# Cari Modülü

## Fiş Türleri
- Alacak Dekontu
- Borç Dekontu
- Cari Ödeme
- Cari Tahsilat
- Cari Virman

## Listeleme
- Filtreler: Cari, Tarih Aralığı, Fiş Türü, Arama

## Form Alanları
- Alacak/Borç Dekontu: Gider/Gelir kartı + Cari satırlar
- Cari Ödeme/Tahsilat: Ödeme Türü (Kasa/Banka) + Ödeme Hesabı + Cari satırlar
- Cari Virman: Cari + Yön + Tutar
